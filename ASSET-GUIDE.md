# Project asset guide

## Required before publishing

Only add original work files that you created or have permission to publish. Do not use stock images or generated filler to imply they are project deliverables.

Suggested structure:

```
assets/
  projects/
    01/
      cover.webp
      01.webp
      02.webp
    02/
      cover.webp
    08/
      poster.webp
      promo.mp4
```

## Recommended formats

- Images: WebP or optimized JPEG; aim for 1600–2400 px on the long edge.
- Logos: SVG or transparent PNG where appropriate.
- Video: MP4 (H.264), preferably compressed for web playback.
- Documents: PDF with sensitive client information removed where required.

## Naming

Use sequential, descriptive names: `01-cover.webp`, `02-layout-detail.webp`, `03-mockup.webp`.

## Update a project page

1. Add the originals under `assets/projects/<id>/`.
2. Update that project's `README.md` with a concise brief and role details that are accurate.
3. Add a preview path to the page only after verifying the file exists.
4. Do not publish confidential source files, client data, or unapproved assets.
